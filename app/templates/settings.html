Phishing delivery providers

For automated phishing-awareness sends. Argus reads provider credentials from the server environment only — never through this page — so secrets stay out of the database and its backups. Set the variables below on the host, then restart Argus.

Email (SMTP) {% if delivery_status.email %}configured{% else %}not set{% endif %} 
ARGUS_BASE_URL=https://argus.yourco.example   # used in tracked links
ARGUS_SMTP_HOST=mail.yourco.example
ARGUS_SMTP_PORT=587
ARGUS_SMTP_USER=drills@yourco.example
ARGUS_SMTP_PASS=••••••
ARGUS_SMTP_FROM=it-servicedesk@yourco.example
ARGUS_SMTP_FROM_NAME=IT Service Desk
SMS / WhatsApp (Twilio) {% if delivery_status.sms %}SMS{% endif %} {% if delivery_status.whatsapp %}WhatsApp{% endif %} {% if not delivery_status.sms and not delivery_status.whatsapp %}not set{% endif %} 
ARGUS_TWILIO_SID=AC...
ARGUS_TWILIO_TOKEN=••••••
ARGUS_TWILIO_FROM=+1XXXXXXXXXX        # SMS sender
ARGUS_TWILIO_WA_FROM=+1XXXXXXXXXX     # WhatsApp sender

WhatsApp only delivers Meta-approved templates, so lure content is usually rejected — treat it as best-effort. Voice and social channels are not auto-sent.
